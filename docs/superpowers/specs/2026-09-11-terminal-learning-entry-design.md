# 终端学习入口设计

## 目标

为现有 AI 学习路线增加一个简单的中文终端入口。用户可以浏览学习阶段和任务、查看完成进度、打开课程链接，并在终端中切换任务完成状态。

## 使用方式

- 在仓库根目录运行 `python learn.py`。
- Windows 用户也可以运行 `start.bat`。
- 主菜单显示总进度及各学习阶段进度。
- 进入阶段后列出任务，并提供切换完成状态、打开链接和返回操作。

## 实现方案

采用 Python 标准库实现，不引入第三方依赖。`learn.py` 负责扫描既有学习目录中的 Markdown 文件，解析任务复选框和 Markdown 链接，生成菜单并响应用户操作。`start.bat` 只负责从仓库根目录启动程序。

程序不创建数据库或独立进度文件。任务状态继续保存在原 Markdown 清单中，使用 `- [ ]` 和 `- [x]` 表示未完成与已完成，因此状态变化可以由 Git 正常追踪。

## 组件边界

- Markdown 解析：读取清单，识别复选框任务、标题和任务链接。
- 进度统计：按文件、学习阶段和全局汇总已完成数与总数。
- 终端交互：渲染菜单、校验数字输入并执行所选操作。
- 状态写回：只替换目标任务行的复选框标记，保留文件其余内容和编码。
- 链接打开：通过 Python `webbrowser` 模块调用系统默认浏览器。

## 数据流

程序启动后扫描五个现有学习目录，读取 Markdown 清单并构建内存中的阶段和任务列表。用户选择任务操作后，程序根据任务对应的文件及行位置打开链接或修改复选框。修改完成后重新读取数据并刷新进度，避免界面状态与文件不一致。

## 错误处理

- 非数字或越界输入不会退出程序，而是显示中文提示并重新选择。
- 缺失或格式异常的清单会被跳过，并显示可理解的提示。
- 没有链接的任务不提供打开链接操作。
- 文件写入失败时保留原内容并报告错误。
- 用户可使用菜单项或 `Ctrl+C` 安全退出。

## 测试与验收

使用临时 Markdown 文件测试任务解析、进度计算和复选框状态切换，不修改真实学习记录。另做一次启动冒烟测试，确认主菜单可以加载现有五个阶段。

验收标准：无需安装依赖即可启动；主菜单正确显示进度；能够浏览全部任务；链接能够交给默认浏览器打开；完成状态切换后对应 Markdown 行准确更新；无效输入不会导致程序崩溃。
