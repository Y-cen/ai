# 本地 Web 学习面板设计

## 目标

将现有数字菜单式终端程序升级为“终端一键启动、本地浏览器鼠标操作”的学习面板。用户可以用鼠标浏览学习阶段、搜索和筛选任务、打开资源链接、勾选完成状态并查看实时进度。

同时修正视频清单粒度：视频课程应按分 P 展示和记录进度，整套课程链接只作为课程入口，不作为可勾选的单个学习任务。

## 启动与运行边界

- Windows 用户运行 `start.bat`，程序启动本地 HTTP 服务并自动打开默认浏览器。
- 服务仅监听 `127.0.0.1`，不暴露到局域网或互联网。
- 默认使用动态可用端口，避免固定端口被占用时启动失败。
- Python 标准库提供 HTTP 服务和浏览器启动，不增加第三方运行依赖。
- 原终端菜单保留，通过 `python learn.py --terminal` 启动，作为无浏览器环境下的备用入口。
- Web 服务可通过页面中的“停止服务”按钮或终端 `Ctrl+C` 关闭。

## 页面结构

页面采用响应式单页布局：

- 顶部显示标题、总体进度、已完成数和任务总数。
- 左侧阶段导航显示五个学习阶段及各自进度；窄屏时折叠为顶部横向导航。
- 主内容区按清单文件和二级标题分组显示任务。
- 每条任务包含复选框、标题、类型、完成状态和“打开资源”按钮。
- 工具栏提供关键词搜索以及“全部 / 未完成 / 已完成”筛选。
- 状态切换后不整页刷新，进度和任务状态即时更新。
- 页面使用原生 HTML、CSS 和 JavaScript，不依赖 CDN，离线也能显示与操作已有清单。

## 数据模型与 Markdown 兼容

Markdown 文件继续作为唯一数据源。后端扫描五个既有学习目录，解析文件名、二级标题、复选框状态以及任务链接。文件名作为资源类别，`##` 标题作为课程或任务分组。

每个任务向页面暴露稳定标识、阶段、文件、分组、标题、URL 和完成状态。稳定标识由仓库相对路径和原始行号构成；写回前后端重新验证该行仍是预期任务，避免页面数据过期时改错行。写回只改变目标复选框字符，保留其余 Markdown 内容与换行格式。

## 后端接口

本地服务提供最小 API：

- `GET /`：返回内置页面。
- `GET /api/stages`：返回阶段、分组、任务与进度数据。
- `POST /api/tasks/toggle`：接收任务标识和客户端当前状态，校验后切换 Markdown 复选框并返回最新状态与进度。
- `POST /api/shutdown`：从页面请求安全关闭本地服务。

所有修改接口只接受 JSON，限制请求体大小，并验证目标路径属于配置的五个学习目录。错误使用明确的 HTTP 状态码和中文 JSON 消息返回。页面显示错误提示，不假装操作成功。

## 视频分 P 整理

- 检查所有视频清单，区分整套课程入口与具体分 P。
- 已按 P 记录的清单保持不变。
- Python 基础中目前只有整套课程链接的条目，需要根据课程公开页面补成可直接打开的分 P 条目。
- 综合项目中的整套视频课程不重复抄录所有分 P；改为指向现有 RAG、Agent 分 P 清单中的项目章节，避免同一视频产生两套互相冲突的完成状态。
- 无法从公开页面可靠确认的分 P 标题不猜测、不虚构，保留课程入口并在界面标记为“课程入口”。

## 前端交互

页面首次加载请求阶段数据，默认选中第一个阶段。选择阶段、输入搜索词或切换筛选条件只修改浏览器中的展示列表。点击复选框后先禁用该项，等待后端确认成功再更新本地状态和全部进度；失败则恢复原状态并显示错误。资源链接以新标签页打开。

## 文件结构

- `learn.py`：保留现有 Markdown 数据层和终端备用入口。
- `web_app.py`：本地服务、API 路由、输入校验与启动逻辑。
- `web/index.html`：页面语义结构。
- `web/styles.css`：响应式布局与视觉样式。
- `web/app.js`：数据加载、搜索、筛选、勾选和进度更新。
- `start.bat`：启动 Web 面板。
- `tests/test_learn.py`：Markdown 与终端回归测试。
- `tests/test_web_app.py`：API、路径安全和页面资源测试。

## 测试与验收

- 数据层测试覆盖标题分组解析、任务稳定标识和精确写回。
- API 测试使用临时仓库和真实本地 HTTP 请求，覆盖读取、切换、过期状态、非法路径、无效 JSON 和请求体限制。
- 页面冒烟测试确认所有静态资源可访问，并检查页面包含阶段导航、搜索、状态筛选和停止服务控件。
- 启动脚本测试确认可启动服务、自动选择端口并正确显示中文地址。
- 保留现有 8 项测试，确保终端备用入口没有回归。

验收时，用户可以从 `start.bat` 打开页面，用鼠标完成浏览、搜索、筛选、勾选和打开资源的完整流程；所有状态变化准确写回 Markdown，且服务只在本机可访问。
