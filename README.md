## 使用规则

- 每个复选框都对应一个外部链接。
- 视频看完后勾选视频；题目在线提交通过后勾选题目；文档读完后勾选文档。
- 先完成“必修”，再根据需要学习“选修”。
- 课程页面分 P 可能更新，因此本计划不自行重写或虚构分 P 标题。

## 终端学习入口

在仓库根目录运行：

```powershell
python learn.py
```

Windows 也可以直接运行：

```powershell
.\start.bat
```

- 查看总体进度和五个学习阶段的完成情况。
- 分页浏览各阶段任务。
- 在终端中切换任务的完成状态，结果会写回原 Markdown 清单。
- 使用系统默认浏览器打开课程、文档或练习链接。
